# Historical Experiments

Documents here preserve completed experiment provenance, including negative results and old commands. They are evidence for past conclusions, not supported MLIPPER usage instructions.

Use the root `README.md` and current `MLIPPER --help` before reproducing an experiment. Keep generated datasets, trees, profiles, and logs outside Git.

Current records:

- [`alisim10k.md`](alisim10k.md) catalogs AliSim 2K/10K placement, Local SPR, NNI, and optimization experiments.
- [`rnasim10k.md`](rnasim10k.md) records the RNASim 10K cross-dataset comparison.
